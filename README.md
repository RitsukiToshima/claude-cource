# ⌨️ タイピングスピード

ブラウザで遊べる、タイピングの速さを競うシンプルなゲームです。

## 遊び方

1. `index.html` をブラウザで開く（サーバー不要）
2. プレイヤー名・モード・制限時間を選んで **スタート**（または Space キー）
3. 表示された文字をそのまま入力する（日本語モードはローマ字を入力）
4. 時間切れで結果とランクを表示。記録はランキングに保存されます

| キー | 動作 |
| --- | --- |
| Space | スタート / もう一度 |
| Esc | 中断してタイトルへ |

## モード

- **英単語** — 一般的な英単語
- **日本語（ローマ字）** — ひらがなの単語を、表示されたローマ字で入力
- **プログラミング用語** — `function` や `console.log` など

## スコアの計算

```
スコア = 打鍵/分 × 正確率²
```

速さだけでなく正確さも大きく影響します。ランク目安: S 400+ / A 300+ / B 200+ / C 100+ / D それ以下

ランキングはモード×制限時間ごとに上位10件をブラウザ（localStorage）に保存します。
同じブラウザを交代で使えば、友だち同士で記録を競えます。

## ファイル構成

- `index.html` — 画面
- `style.css` — デザイン（ダークモード対応）
- `script.js` — ゲームロジック
- `words.js` — 出題ワード集（ここに単語を追加すれば問題を増やせます）
